# 血糖平衡實驗室

網頁入口是 "index.html"，與 "style.css"、"app.js" 一同使用。

現有公開網頁：[血糖平衡實驗室](https://blood-glucose-lab-hk-f5.idealloom32.chatgpt.site/)


以瀏覽器開啟同資料夾的「血糖平衡實驗室.html」即可使用。所有樣式及程式已包含在一個檔案內，無須網絡、安裝或登入；只有頁底科學參考連結需要網絡。可把 HTML 檔派發給學生或上載至學校學習平台。

## 建議教學流程（約 12 分鐘）

1. **預測與探索（5 分鐘）：** 三個情境各選一個預測，再啟動模擬。使用暫停或「下一步」，比較曲線與胰臟、肝臟的反應。
2. **機制挑戰（4 分鐘）：** 分別排列升高及降低路徑；預測調節後曲線方向；解釋負反饋。點擊已排卡片可移除，錯誤答案可直接改選。
3. **回顧與檢查（3 分鐘）：** 閱讀三個重點、完成三題理解檢查，再向同學口述其中一條調節路徑。

## 版面及操作

桌面並列曲線與器官反應，手機採直向排列。點擊器官、激素及路徑箭頭可查看解說，視窗開啟時模擬會自動暫停，關閉後可手動繼續。探索模式提供觀察提示；挑戰模式跳至獨立作答區。

「重設」清除目前情境的預測及模擬。「重做理解檢查」清除三題答案。進度只保留在目前頁面，重新載入即清除。播放速度只改變展示速度，不改變圖上模擬的分鐘數。

## 科學內容

- 體內平衡指內在環境維持相對穩定；血糖仍會在範圍內波動。
- β 細胞增加胰島素分泌，促進部分身體細胞攝取葡萄糖，及肝臟將葡萄糖轉化為糖原。
- α 細胞增加胰高血糖素分泌，促進肝臟分解糖原並釋放葡萄糖到血液。
- 調節反應抵消最初變化，返回示意正常範圍後，增加相應激素分泌的刺激減弱；基礎分泌並不停止。
- 血糖及激素分泌量均為教學用簡化數據。4.5–6.5 mmol/L 是此活動的示意範圍，不是臨床診斷標準；激素值沒有臨床單位。
- 運動例子假設肌肉消耗葡萄糖增加，持續約 45 分鐘；實際反應受強度、時間及其他激素影響。未進食例子由上一餐後約 6 小時開始，假設肝臟仍有糖原儲備。
- 本活動聚焦兩種激素與肝糖原，並未包含其他激素及葡萄糖生成等全部調節途徑。

參考：[OpenStax Biology 2e：Regulation of Body Processes](https://openstax.org/books/biology-2e/pages/37-3-regulation-of-body-processes)、[Endotext：Glucagon Physiology](https://www.ncbi.nlm.nih.gov/books/NBK279127/)。

## 已完成的檢查

- 實際瀏覽器操作三個情境各十二步；驗證分鐘、血糖值、激素值及器官文字同步。
- 驗證升高路徑及降低路徑、恢復範圍時的刺激減弱提示、非零基礎分泌及末段小幅波動。
- 操作自動播放、暫停、逐步播放、速度切換、重播、重設。
- 驗證十二種解說、使用指南、關閉按鈕及 Escape 鍵。
- 測試兩條排列流程的正確、錯誤及未完成回饋，並驗證卡片移除及清除功能。
- 測試曲線方向、負反饋及三題檢查的全部選項；確認可改答、正確計分、完成訊息及重做。
- 檢查 320、390、768、1440 像素視窗；修正最窄畫面的橫向溢出，驗證手機排列卡片觸控高度至少 44 像素。
- 驗證 JavaScript 語法，檢查瀏覽器沒有程式錯誤；離線檔案包含全部 CSS 及 JavaScript。

手機測試使用瀏覽器視窗尺寸模擬，未於實體 iOS 或 Android 裝置測試。
